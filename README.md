# MKW Result Tracker
This program lets you keep track of your Lounges and your track-specific stats with 2 clicks per race.

(Connecting tracks are currently not supported. I would recommended just using the track of arrival for your input.)

# Getting Started
- Download the zip from the latest release
- Unpack and put the folder whereever you want (and optionally create a shortcut)

When using the program for the first time, it will create a file "Results.json" in the same folder. Leave it be, that file holds your stats

# Controls
- Click Button at the top to switch between 12P and 24P
- Button on the top left side starts a Lounge
- Click Track, then Placement to register race
- Right-Click Track, then confirm below to delete a registered Placement (for misinputs, during Lounge use the dedicated "Delete last race" Button instead)

Executable file in the zip was created using "pyinstaller" so neither Python nor necessary libraries are needed to run the program.
You can also download and use the .py file instead. To run that though, you need Python installed, as well as the libraries "tkinter", "json", "PIL" and "matplotlib"
